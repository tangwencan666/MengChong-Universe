# 萌宠乱斗

支持本地人机对战与双客户端真人联机原型，只包含用户确认的**奶娃、刀盾、鲸鱼娘**。不依赖账号登录、FastAPI、Electron、QQ、模型或数据库。

本次在给定 WeiBiYe 源码中没有找到旧“萌宠乱斗”；用户确认后，在这个独立目录新增实现。没有改动原 React 路由、桌面窗口或聊天链路。

## 启动

Windows 双击本目录的 `start-game.cmd`，随后打开 <http://127.0.0.1:43926>。终端需要保持运行，Ctrl+C 停止。

也可以在 PowerShell 中执行：

```powershell
Set-Location 'D:\AIProjects\WeiBiYe-worktrees\consumer-desktop-pivot\games\pet-brawl'
node .\server.mjs
```

使用现有 Node.js 22.12+，不需要 npm install 或下载依赖。默认端口已占用时不会终止原服务，可执行 `node .\server.mjs 43927`，再访问新端口。

## 本地真人联机

保持同一个游戏服务运行，在本机两个浏览器窗口或标签页中打开同一地址，各自选择角色和“真人联机（本地原型）”。每个页面是独立的临时玩家，可以选择相同角色。

- 好友约战：一方点击“生成格斗码”，另一方填写8位格斗码后点击“加入好友对战”。格斗码10分钟有效，房间只容纳两人。
- 随机匹配：格斗码留空，点击“随机匹配”；需要另一名真人也进入队列，没有人时会继续等待，不会自动用电脑冒充真人。可随时取消，2分钟无人匹配会结束本次等待。
- 人机练习：选择“电脑对战”，随时与本地电脑角色练习。

联机时双方各自操作自己的角色，移动、伤害和胜负由服务端统一计算。紫色P1、橙色P2和“你/对手”标记会根据各自视角显示。Esc是菜单，不会暂停对手；结束后需要双方同意才会重开。切出窗口会释放自己的按键，短时断线暂停等待，超过15秒结束房间。

这不是公网发行：服务仍只监听 `127.0.0.1`，其他电脑无法通过本机地址加入。房间、队列和临时身份仅在内存；刷新页面或重启服务后需重新创建房间/匹配，未接入正式账号、成绩或持久化重连。真实互联网延迟、负载与公开部署尚未验证。素材仍仅限本地验证。

## 操作

选择自己的角色、电脑对手和难度，点击“开始乱斗”。点击场地可以重新接管键盘。初次可选“轻松练习”。

双方可以选择同一个角色，选自己的角色不会自动替换对手。紫色“P1 · 你”和橙色“CPU · 电脑”标记显示在血条、角色头顶和脚下；交换左右位置后标记仍跟随各自一方。同角色的生命、体力、冷却和技能音轨分别独立，结算会明确获胜方。

同角色版本实际验证：98项离线测试、可见Chrome同角色专项6组和完整游戏13组通过，包含三种同角色组合、左右换位、两方同时播放技能原声及统一静音。证据为新的 `.verification/pet-brawl/mirror-match-*/` 目录。

| 按键 | 操作 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| W 或上方向键 | 跳跃 |
| J | 轻击；连续按或按住可以衔接三连击 |
| K | 重击，有明显起手，命中击退更远 |
| U | 专属技能，冷却5.5秒 |
| 按住 S | 正面防御；松开结束，空中无效，消耗体力，仍有少量伤害 |
| Space | 短距离闪避，起步短暂无敌，消耗体力 |
| Esc | 人机暂停/继续；联机打开菜单，不暂停对手 |
| R | 人机当前组合重新开始；联机结束后双方同意重开 |

窄窗口还提供屏幕操作按钮，松开或取消指针会释放按住状态。人机切到其他窗口自动暂停；联机只释放自己的按键，不暂停对手，也不会抢回焦点。

跳跃高度明显提高：奶娃约358、刀盾约332、鲸鱼娘约345场地单位，约1.3秒落地；仍为单次地面起跳，空中继续按跳跃不会额外升高。对战时血条独立在场地上方，高跳会带动镜头，落地后镜头恢复；不靠缩小角色伪装跳高。

三名电脑角色都能跳跃接近，并根据可见的低位飞行物、重击和技能起手尝试跳跃躲避。普通难度较积极，轻松练习频率较低；每次起跳有冷却，空中、受控、出招和闪避期间不会强行追加起跳。

生命归零结束一局；90秒计时结束时比较剩余生命比例，比例相同为平局。命中停顿和暂停不消耗比赛计时。结算可重开或重新选择角色。

奶娃：110生命、移动较快，U技能“捧腹大笑”使用用户视频的大笑关键帧及原声。起手0.28秒后，每0.1秒在周围205范围判定一次，每次1点伤害和0.13秒僵直，最多21次、全中仍合计21点；站在范围外、闪避或打断可以避免后续伤害，不补算错过的伤害。正面全挡合计2点擦伤，控制会自然解除；一次消耗28体力，冷却仍为5.5秒。

刀盾：125生命、移动较慢，U技能“冲锋横斩”：举盾冲刺，碰撞造成6点伤害并停步击退，随后向前310范围挥砍，造成14点伤害并再次击退。两段全中20点，正面全挡合计2点擦伤；没撞到也会挥砍，不会把碰撞伤害转移到挥砍。一次消耗28体力，冷却5.5秒，起手/冲刺期间保留正面减伤，动作朝向锁定。

鲸鱼娘：100生命，U技能“三连星弹”参考用户视频的抱手蓄力、伸掌放光球动作。三段各5、5、6伤害，全中合计仍为16；三段均成功格挡时合计2点擦伤。一次消耗28体力，冷却仍为5.5秒。每颗可单独跳跃/闪避，躲掉的伤害不会转移到其他段。J轻击和K重击不变。

## 素材与表现

原图来自用户图片库，直接复用此前 P8.5 生成的透明PNG副本，再逐字节复制到 `assets/`。没有修改原图、换角色、生成新人物或镜像互换刀盾装备。详细哈希见 `assets/provenance.json`；完整原素材出处仍见项目P8.5资源记录。

常规角色动作用原图片变换、受击闪白、挥击弧、光球、伤害数字和有限震屏。奶娃大笑例外：采用本次用户视频2.2–3.6秒提取的8张真实关键帧，Canvas只显示角色区域并在预载时处理相连白色背景，保留嘴部、牙齿与表情；是轻量关键帧循环，未宣称还原视频全部60fps动作。原来的三张宠物PNG不修改。

音效默认开启：奶娃U用本次视频2.2–4.8秒的2.6秒原声，鲸鱼娘U用此前视频开头约2秒原声，刀盾U用录屏开头准确2秒原声；每次技能只播一次、不循环，其他效果为本地合成。顶部可统一静音，暂停会暂停原声，重开/结算/返回选角会停止旧声音，奶娃被打断后也会停止大笑原声。尊重系统减少动态效果设置。
