# P8.3 受控内测发行：架构检查与实施边界

起点：d542866，487个现有源文件、5074份历史验收文件已保存哈希基线；既有未提交后端/前端成果保留。P8.1真实在途取消、上游中断和取消费用继续未验证。

## 架构检查

Electron使用本地BFF网关，React/宠物使用独立、受限的会话分区，后端持有模型凭据。当前网关只接受127.0.0.1 HTTP，不能将远程HTTPS简单替换字符串后称为可发行：必须同时处理可信端点、TLS验证、Cookie/CSRF和跨来源隔离。客户端不会加入模型凭据。

P8.2已有未签名per-user NSIS构建及解包程序实测，没有真实安装/升级/卸载证据。本机当前为Windows 11家庭版、非提升权限令牌。隔离安装采用专用验证appId、目录及profile，避免覆盖现有应用；它不能替代生产appId、干净标准用户机器或下载后SmartScreen测试。

聊天已有User→Pet/记忆→Session→Generation行锁、幂等、最终派发授权及终态屏障。钱包仅有Protocol，P8.1内存请求计数不能承担跨进程免费额度。聊天数据库版本0006与已有保护保持不变：新增额度使用独立Alembic版本表/元数据，在同一数据库事务中使用额度表，不推动历史验收库迁移。仅全新P8.3夹具安装新schema。

## 阶段计划

1. 构建独立验证身份的0.1.0/0.1.1安装器，验证安装、启动、覆盖升级、卸载及数据保留；保留证据。检查未签名状态和系统提示，不修改Windows安全设置。
2. 设计独立测试环境、域名/证书/邮件/备份/恢复和HTTPS接入；默认远程接入关闭。注册、登录、聊天先在本地TLS与合成账户、Mock模型环境验证，不部署公开服务。
3. 实现邀请码一次性领取、账户终身/每日额度、账号并发、全局每日请求及预算预留、派发前复核、终态结算和审计。通过真实隔离PostgreSQL的多连接/多进程竞态测试，不依赖单进程锁。
4. 增加明确告知、默认关闭的最小诊断/统计、本地反馈导出与留存聚合；记录真实硬件测试矩阵，不将事件模拟称为休眠或多屏硬件通过。

## 额度与成本边界

额度以唯一generation预留，重复HTTP请求不重复占额；Mock不扣真实模型额度。派发标记提交后才允许SDK请求，已派发任务即使崩溃/失败/取消，也不能自动重新派发或自动退还未知费用。准入前失败可释放。取消不承诺上游中断或免费。

全局UTC日期计数通过数据库行锁保护；跨日排队请求拒绝，不把昨日额度搬到今日消费。保守预算账本的扣减上限与实际供应商账单区分。上线前必须确认允许模型、输入/输出硬上限、价格版本和单请求保守费用上界；未确认时保持真实调用关闭。本轮全部SDK调用使用离线替身。

## 风险与必须等待的事项

- 未签名包可能触发SmartScreen/安全软件提示；本地生成文件通常没有互联网来源标记，不代表下载体验已验证。不会关闭SmartScreen、杀毒或安装根证书来通过测试。
- 本机单屏和当前DPI不能证明多屏热插拔、其他缩放、低配置及睡眠恢复；不自动使整机休眠影响用户工作。
- D1/D7需要跨日去标识化关联，不能宣传为绝对匿名；只在明确同意后记录最小事件，拒绝正文、凭据、设备指纹与任意错误字符串。未成熟队列不进入D1/D7分母。
- 安装成功率需要经同意记录的安装尝试分母；首次启动不能冒充所有安装尝试。Mock与真实模型的首次互动分开统计。
- 公开部署、生产域名/证书、真实模型费用、外部发布和邀请真实用户需要用户另行确认。本轮只生成可审查结果，不推送或发布。
