# P8.3 隐私、反馈与设备验收边界

## 告知与最小统计

账号注册、登录、聊天和记忆仍由既有授权规则保护。新增“内测与反馈”页面在读取告知前不允许同意，统计默认关闭，明确保存后才开始。统计不影响额度领取。退出统计会删除该账号对应的统计事件；重新同意生成新的随机化代号，不能与旧队列拼接。

只收集去标识化代号、UTC 日期、队列日期及白名单事件。代号由后端 HMAC 和随机盐生成，内部同意记录关联账号，因此称为**去标识化**，不能承诺绝对匿名。请求不接受自定义正文、时间、用户 ID、聊天内容、token、堆栈、设备指纹或任意错误字符串。生产需独立后端 HMAC，不能使用测试常量。

活跃事件只在已同意的宠物页面收到可信键盘/指针交互且页面可见时发送，一日幂等；不记录按键值或坐标。聊天完成事件由后端终态提交时产生，Mock 和真实模型分开计数。后台故障/完成不冒充用户当日主动活跃。额度结算与统计保存点分开，统计不可用不能回滚聊天或重复派发模型。

首次互动率以已明确同意的队列为分母，D1/D7 按 UTC 自然日计算且排除未成熟队列。聚合代码不输出个人事件。没有真实内测队列时不能报告真实留存率。

安装成功率需要**同意后的真实安装尝试 ID 分母**与对应成功记录。当前仅提供该聚合规则及回归测试，没有安装阶段采集/发送流程，因此成功率返回未知，不能用启动人数冒充安装尝试。本地 NSIS 成功证据也不是线上安装成功率。发行前需审查安装告知和失败反馈方案，再启用该采集。

事件保留 30 天的删除函数已提供，未启用后台共享库任务。部署时必须配置并验收定期清理；没有清理任务时不能声称实际保留期限已经生效。

## 故障反馈

“内测与反馈”可以手动保存最小 JSON 反馈单；只有固定类别、随机编号、时间和告知。下载仅允许已登录主窗口的指定页面、指定文件名/类型，16KiB 上限；会话切换会取消导出。文件不会自动上传，组织者的反馈渠道尚未配置。

连接失败也可从托盘打开无需登录的本地帮助，复用一个无脚本窗口，独立无凭据分区，禁止网络、下载、权限和跳转；只显示版本、随机编号、时间及固定连接类别，用户自行复制。不会读取日志/聊天/环境变量。可选本地诊断沿用固定事件白名单、容量限制与默认关闭，不上传崩溃 dump 或内存文件。

## Windows 与卸载策略

安装器采用 per-user、asInvoker、禁止自动提权，覆盖升级和卸载默认保留用户 profile。profile 位于安装目录之外；里面的宠物位置和可选本地诊断不会因升级/卸载自动删除。认证 Cookie 在内存分区，退出清理；聊天和记忆保存在服务端，卸载不删除账号或服务端数据。

若用户要求彻底删除本地数据，先退出全部属于本应用的进程、确认 profile 绝对路径及归属，再由用户明确选择删除；本轮没有新增自动递归删除功能。删除云端账号/记忆另走受控授权流程，不能把卸载视为删除服务端数据。

本地未签名包不具备发布者签名信誉。没有互联网来源标记的本地测试不能证明下载后的 SmartScreen/杀毒提示；不得关闭安全软件或让普通用户安装测试根证书。

## 必须保留为未验证的设备项目

| 项目 | 本轮可做 | 真实内测前补测 |
| --- | --- | --- |
| 休眠/恢复、解锁 | 电源事件去抖、取消监听、重新授权和窗口夹取的单元测试 | 空闲/聊天在途/断网时真实休眠与恢复，无重复请求、不抢焦点 |
| 多屏/热插拔/负坐标 | 既有几何/DPI 模拟边界及恢复流程回归 | 双屏负坐标、拔主屏、100/125/150/200% 混合 DPI |
| 低配置 | 当前设备测量及明确标注的模拟负载 | 独立 4GiB/8GiB 设备或受控 VM，观察 CPU、内存、输入与启动延迟 |
| 普通用户权限 | 本机非提升令牌下独立验证身份安装/启动/升级/卸载 | 全新标准用户账户、不同 Windows 版本、中文用户名和受限目录 |
| 安全提示 | 文件签名状态、打包内容检查 | 经批准的真实下载渠道、MOTW、SmartScreen、主流杀毒 |
| 账号/宠物隔离 | 本地 HTTPS 实际 React/API/SSE 和后端离线回归 | 独立后端上真实受邀用户的并发体验 |

不会自动休眠当前电脑、安装虚拟显示驱动、修改系统安全策略或占用其他项目端口。模拟事件不能写成真实硬件通过。
