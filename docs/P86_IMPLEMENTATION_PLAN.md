# P8.5.1 / P8.6 本地实施方案

基线 233c7444，193 条既有未提交路径、612 个源文件和 16,259 个历史证据文件已保存哈希和源码副本。P7 原图只是重命名，兼容解析只在原路径缺失时按完整 SHA256+大小在指定图片库内查找唯一原图；原路径存在但内容变化仍失败。189 项桌面测试全通过后开始 P8.6。

复用 Electron 主进程动作和有界移动、五窗口上限、账号认证与宠物 UUID。新增纯本地种子决策引擎，情绪/需求、实例对关系、临时结盟、低概率双边冲突与第三方调解、免费互动幂等流水、参与者可见的结构化共同事件。单一可取消 timeout 按下次决策/事件阶段/气泡到期唤醒，不新增窗口或进程。拖动、私聊生成、隐藏、收回优先；后台降低频率，离线结算最多 15 分钟，不追补事件。

社会状态按认证 owner 分文件原子保存，UUID 关系，不按名称/品种当身份。最多保存 200 条最近事件、512 对关系和 512 条免费道具流水，界面明确说明。流水幂等键加版本约束，旧请求即使退出流水窗口也不能重放消费。安慰始终免费，食物为本地免费提供一份并即时使用，无余额/支付。社会事件从未注入 AI，参与者接口为未来检索留边界，不宣称 RAG。

现有 SQL 模型、私人授权记忆、DeepSeek 门控不改，不迁移数据库。新状态文件损坏/跨账号替换则禁用社会功能而保留文件，正常聊天仍可用。退出只关闭本次进程，不清理其他服务。

依次实施：P7 修复 → 纯引擎/存储/确定性回归 → 主进程权限与调度 → 管理界面/右键免费互动/情绪气泡 → Windows 受控种子验收 → 五宠 30 分钟性能 → 回归、数据/历史保护审计、仅本轮本地提交。P7 测试虽原为未跟踪文件，本轮用户明确要求修复，保留原有全部图像断言，将该相关测试及其原有 PNG 检查依赖纳入提交；依赖原文件内容不变，其余 191 条原有未提交成果继续保留。测试触发器仅模块测试接口，不进入 renderer IPC 或普通用户菜单。

Windows 排查中新增最小本机代理修复：HTTP 上游请求使用独立连接，避免复用已关闭的空闲连接；不自动重试任何请求，身份、来源、Cookie、CSRF 和 SSE 保护不改。确定性离线旧代码红测及新代码通过结果单独保存；现场曾出现的 502 未记录 socket 错误码，不宣称已经唯一确定其底层错误原因。
