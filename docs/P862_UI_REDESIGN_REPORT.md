# 萌宠溜达 P8.6.2 UI 改造报告

日期：2026-11-03。状态：`P862_UI_WINDOWS_VERIFIED`（本地 UI 与离线业务回归）。

## 视觉依据与范围

本轮实际读取用户上传的第二版设计图 `codex-clipboard-4f6e6432-275d-4f2d-9520-c51e0a2bf44c.png`，未再使用缺失的桌面参考文件，也未用其他设计替换。参考图 SHA-256：`46a06715c1856ae609f10c3c8508222cf83b00859562a35ec793e3279d8a69c4`。原图的逐字节副本保存在新的汇总证据目录中，未修改上传原图。

改造限于 React 呈现、样式、导航、产品显示名称及相应本地测试。没有重构宠物社会引擎、聊天、记忆或数据库。

## 主题与布局

- 新增统一 `theme.css`：主色 `#1677FF`、文字 `#102B60`、背景 `#EAF4FF`、卡片 `#FFFFFF`、次级文字 `#64748B`、边框 `#D4E5FA`。可读性较强的按钮底色采用 `#0963DA`。
- 顶部蓝色星光品牌、蓝白波纹；左侧五个线性导航入口；中央桌面组合和伙伴社交卡片；右侧项目简介、六项功能说明、山峦和松树。
- 背景是本轮原创静态 SVG，不加载外部图片或添加动画计时器。没有新增猫爪装饰；既有宠物图像内部图案不被擦除或重画。
- 组合卡片按真实状态展示宠物头像、名字、在桌面标记、聊天入口及空位；没有固定写死四只。仅可见实例计入五只上限。
- 伙伴面板保留心情、需求、关系、结盟、共同事件、免费互动流水、删除事件确认、气泡/静音/频率设置和十分钟安静；新增参考图所需的一分钟安静入口，调用已有设置接口。
- 八角色领养及已领养列表完整保留在主要功能区下方。原先悬浮盖住页面的模板入口改为普通页面链接，原路由仍可访问。
- 保留历史聊天、新建聊天、授权记忆、账户、隐私、费用及内测反馈入口。社交详情按原有展开交互组织，必要功能均可访问。
- 宽屏为三栏；中等宽度缩小简介；1100 像素及以下将简介移到主区域下方；窄屏导航使用抽屉，宠物卡片和按钮自动换行。

## 品牌更名

主界面、顶部标题、页脚、欢迎页、登录/注册、聊天窗口、启动错误提示、应用显示名称、托盘提示与退出菜单均改为“萌宠溜达”；副标题为“你的桌面 AI 宠物伙伴”。账户、设置、关于和记忆页面沿用统一外壳。

安装配置中的产品名、快捷方式名、卸载显示名及安装文件名已更新；便携包元数据和安装器额外元数据使用新产品名。本轮未重新构建、安装、覆盖升级或卸载 NSIS，不将配置单元验证写成安装验收。

内部兼容标识保持不变：目录名、Python 包、数据库、迁移、API、环境变量、`com.weibiye.desktop`、既有 `WeiBiYe` 用户数据目录和可执行文件内部名称。保留既有用户起的名字、历史聊天、人格快照和提示词，不进行数据中的品牌字符串替换。

旧的未跟踪连接帮助组件保持原始字节；主进程只对它的固定旧标题做显示兼容映射，不重写任意网页或用户会话标题。该标题映射在真实 Electron 加载中验证通过。

## 功能与数据保护

- P8.6.1 召唤修复未改变：任意已领养实例可以按 UUID 召唤，隐藏窗口不占五只显示名额，实际第六只被拒绝；收回后可选择另一只。
- 八种角色、同品种多实例、人格、长期记忆、关系、事件及动作映射保留。透明悬浮窗口使用独立文档，不加载新前端主题。
- 管理页静态预览按已登记 `species_id` / `appearance_id` 映射；P7 按账号及实例授权的临时私有外观覆写仍仅作用原悬浮窗口，不为显示头像而放宽旧 IPC 隔离契约。
- 本地安慰、免费鸡腿具有真实社会流水；一分钟安静在实机上核对实际期限。已有幂等性与冷却没有更改。
- 选定宠物聊天获得真实本地 Mock SSE 回复，刷新后恢复已保存消息；这不是本轮真实 DeepSeek 验收。
- 跨账号访问返回 404、旧实例召唤被拒绝，新账号没有恢复上一账号的桌面实例。
- 原有共享 PostgreSQL 仅做只读前后快照。集群 `7703042374370492450`：共享库 `0005`/26 表、旧 P6 隔离库 `0006`/34 表，schema 和数据哈希均一致。本轮测试写入仅在新建的 SQLite 测试目录中发生。
- 额外召唤专项预先建立两个非空记忆、两个会话与四条本地 Mock 消息，再对宠物、会话、消息、记忆等相关表做前后行哈希比较：完全一致。原八只顺序、位置及关系未变，未调用宠物 DELETE。
