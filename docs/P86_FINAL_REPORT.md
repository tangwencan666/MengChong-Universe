## 2. 本地自主行为引擎

复用现有八角色、Electron 窗口、P8.4 动作优先级/碰撞与多屏边界、P8.5 实例身份与五宠上限。没有新增社会模拟进程、额外桌面窗口或数据库迁移。

- `p86-society.cjs` 是独立于 Electron 的种子规则引擎，保存每个实例的情绪、精力、饥饿、无聊、社交需求、行为冷却和最近事件。八角色保留；同品种不同 UUID 的数值人格、状态、关系和事件独立。
- 数值人格由品种基础倾向与实例随机种子构成，行为综合需求、社交/竞争倾向、关系、距离、同屏条件与随机值。当前不解析自定义人格正文或私人聊天来生成数值人格；AI 人格快照仍由原有系统独立管理。
- 支持散步、观察、自己玩、休息/醒来、问候、一起玩、合作、靠近、回避、争玩具和和解。事件不是固定时间剧情，也不在后台调用大模型。
- 前台通常 25–45 秒进行下一次决策，后台通常 90–110 秒；“更安静”增加 60 秒。阶段结束、气泡消失和情绪到期按最早到期时间安排一次可取消的社交 timeout；已有窗口运动时钟继续复用，没有增加高频社交轮询。
- 只有同屏、可见、允许随机互动、未被拖动且不处于高优先级点击/AI 思考或说话状态的实例能参与。事件期间跨屏、超距、隐藏、收回或忙碌会中止，不虚构共同活动完成。
- 自动移动仍受最小间距和显示区域约束；挤在一起时允许拒绝移动。固定时钟种子支持重放测试，但普通用户不会运行测试触发器。

## 3. 情绪、需求、关系和有限冲突

八类情绪为开心、平静、好奇、生气、委屈、难过、害羞、困倦。需求保持在 0–100，情绪带截止时间并自然恢复。休眠或离线结算最多 15 分钟，不补播错过的事件，不制造持续负面压力。

每对关系使用排序后的两个宠物实例 UUID 作为键，记录好感、信任、熟悉、竞争、最近冲突/合作和临时结伴期限。友好事件逐渐增加熟悉与信任；满足阈值后显示朋友，合作可产生 90–120 秒临时结伴。当前是三者合作和实例对短时结盟，没有独立命名的永久帮派模型。

争执仅有两名争玩具的参与者，最多第三名和事佬，不实现群体攻击或伤害。全局争执冷却 12 分钟、双方各 15 分钟；普通友好互动远多于冲突。生气约 30 秒，委屈/难过约 45–75 秒自然恢复。真实发生的争执可以被用户调解，之后也可能由本地决策自然和解。

本地台词由实际事件代码、角色和种子选择，每条气泡约 7 秒，没有把用户未做过的选择写进台词或记忆。提供社交、冲突、气泡、静音、频率和全部安静十分钟控制；本轮没有音频，社交静音会抑制本地气泡。单宠随机动作和自动移动继续使用原有右键设置。

委屈/难过的外观是**名字旁的泪滴提示和本地短句**，不修改原图五官，不宣称已有完整逐帧哭泣动画。其他动作继续使用已有素材和轻量 CSS 变换。

## 4. 用户参与与免费道具

“我的宠物”增加心情、需求、关系和共同事件面板，右键菜单提供免费互动。支持抚摸、安慰、鸡腿、小鱼干、玩具、小毯子、调解和支持。点击宠物仍打开对应实例的原有聊天入口。

安慰始终免费。道具操作是本地免费提供一份并原子记录使用一份，没有真实货币余额、支付或扣费。使用请求 UUID、状态版本、750ms 同类操作冷却及界面忙碌锁防止双击/重试重复消费；即使旧请求退出 512 条流水窗口，旧版本也不能重放。

只记录实际选择。调解和支持改变当前真实事件与关系，不处罚没有获得支持的宠物。用户投喂能降低饥饿、改善情绪；道具与操作记录可随正常退出恢复。

## 5. 共同事件记忆、权限和保存

共同事件包括事件 UUID、类型、参与实例、起止时间、真实用户操作、关系变化、结果及参与者可见范围。事件仅保存结构化枚举与实例 ID，不保存私人聊天正文、模型 Token 或 API Key。

- 主窗口通过现有认证确认 owner；宠物窗口的查询范围固定为该窗口绑定的实例，不能传入另一个宠物 ID 扩大范围。聊天窗口不能调用主界面的社交管理接口。
- 同账号同品种的非参与者不能读取事件，其他账号不能读取该 owner 的状态。改名不会改关系或事件身份；收回不删除关系/记录。
- 所有者可以查看和确认删除共同事件。删除会清除事件本体、各实例最近事件引用、气泡和活动引用，参与者接口不再返回它；既有关系聚合数值不会追溯回滚，界面明确说明。
- 共同事件**尚未注入 AI 聊天上下文**。私人授权长期记忆沿用原有隔离，不与事件混合，不宣称已经实现 RAG、Embedding 或 pgvector。
- 状态在当前应用 profile 的 `pet-society-v1/<owner哈希>.json` 按账号原子保存。损坏、跨账号替换、非法结构或链接路径拒绝覆盖，暂停社交并保留原文件；聊天入口保留。本轮没有提供跨设备同步或文件加密承诺。
- 保存上限为 256 个已参与过本地社会的实例、512 对关系、200 个最近事件、512 条免费流水、1MiB 文件。可见宠物仍最多 5 只；超过这些本地社会存储规模的体验尚未验收。

- 重启结果覆盖“恢复桌面组合操作完成后正常退出”。在恢复组合尚未完成时退出的事务化恢复尚未强化，不能把测试中途分配窗口的数量当作操作完成。
- 社交事件执行期间的独立外部焦点专项尚未额外覆盖；已验证普通后台焦点探针，社交调度代码不调用自动 focus/show，但不能把受保护长测冒充完整焦点实测。
- 真实自发低精力睡眠未必在 30 分钟内发生；低精力休息/自然恢复由离线用例验证，睡眠/醒来动画通过实际角色动作测试。
- 当前使用原有静态素材、CSS 动作与情绪提示，没有完整新表情逐帧集、真实音频、永久帮派、跨设备同步、AI 事件检索或支付。
- 鸡腿投喂目前使用开心动作及短句反馈，没有专用进食逐帧动画。
- 建议 P8.7 先做硬件/休眠/异常恢复专项与更长长测，再完善原创情绪素材和小团体表现。若未来接入事件 RAG，应先设计参与者权限、删除同步和显式授权，不读取其他实例私人记忆。
