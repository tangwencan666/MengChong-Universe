# P8.4 本地开发计划与边界

基线 d542866；528 个源文件与 14,347 份既有验收文件已保存哈希及源文件副本。既有 P8.1～P8.3 未提交成果保留，不推送，不公开发布，不调用真实模型，不修改共享库。

1. 以一个公开宠物目录 JSON 注册五种模板。复用 appearance_config.asset_id、独立宠物 UUID、人格字段及既有聊天/记忆授权，不改数据库结构。新增耄耋与哈吉米使用本项目原创 SVG 占位资源，无外部图片、音频或下载。
2. 把动作、优先级、持续时间和冷却放入目录；每只宠物一个纯状态机，复用宿主计时器。隐藏/退出/拖动优先，聊天与点击可中断随机动作。仅恢复安全的睡眠/待机状态，不恢复过期的生成状态。
3. 空闲随机动作低频触发；自动移动默认关闭，可逐宠开启/关闭，使用既有多屏和防重叠几何。鼠标靠近时暂停移动。双宠协调只读取当前同账号的公开模板、动作与位置，不传递会话或记忆。
4. 用受限本地动作菜单、原创有界 CSS/SVG、按需资源缓存和隐藏时卸载图片控制 CPU/内存。保持聊天窗口复用、权限复核、端口和退出保护。
5. 离线单元、类型/ESLint/构建、现有回归、真实 Windows/Electron 物理拖动/重启恢复、单/三/五宠性能，以及至少 30 分钟五宠稳定性实测。真实多显示器热插拔、其他 DPI/设备等不能自动执行的项目明确保留未验证。
6. 只提交相对本轮基线的 P8.4 增量。报告记录工作树的既有未提交前置依赖，不把它们夹带提交。若无法安全分离或出现并行变更，保留成果并报告，不恢复或强行覆盖。
7. 保存最终报告、核对历史哈希/共享库只读快照、关闭本轮进程。只有任务与提交成功且其他会话/任务/未保存工作可确认为安全才按授权关机；不使用强制关闭，无法确认就跳过。

风险：五个 Chromium 宠物渲染进程的内存会高于三宠，需实测而非承诺沿用三宠数值；新动作是原创简约占位表现，不宣称成品动画。P8.1 真实上游取消与 P8.3 公开发行门槛不因本轮而改变。
