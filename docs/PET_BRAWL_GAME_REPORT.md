## 实现的玩法

- A/D移动、W跳跃，另支持方向键；世界边界、重力、着地和双方推挤框。
- J轻击及三段衔接、K有起手的重击、L按住正面格挡、Space短暂无敌的闪避、U独立角色技能。
- 奶娃近身震地、刀盾带正面保护的突进、鲸鱼娘可见浪花弹体；技能5.5秒冷却，攻击/防御/闪避消耗体力，体力逐渐恢复。
- 实际命中范围和方向、一次挥击只命中一次、击退/浮空、硬直、受击闪光、数字/火花/连击提示、有界命中停顿和震屏。原图片变换表现，不冒充完整逐帧动画。
- 两档本地规则电脑对手，按距离、体力与可观察起手决定移动/出招，不使用大模型。
- 生命归零与90秒计时结束判胜，按剩余生命比例比较不同血量角色；同时归零/比例相同有平局，终态后不再伤害。
- 暂停、切换窗口自动暂停、重开、结算后重新选角；窄窗口屏幕按钮，指针取消时清理按住状态。
- 快速短按跨帧保留，避免keydown/keyup在同一渲染间隔内丢失；暂停、重开、失焦清理输入。
- 音效为可选WebAudio本地合成，默认关；系统减少动态效果偏好会降低非必要动效。

计时在命中停顿/暂停期间停止。当前是一局制对战电脑，没有联网、双人控制、排位、账号奖励或宠物数据写回。
