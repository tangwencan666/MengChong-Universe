# 奶娃：捧腹大笑、原声及持续声波

2026-11-08，仅改独立小游戏，不改AI聊天、桌面宠物、QQ、账号或数据库；没有模型调用、外部请求、提交或推送。

## 技能

奶娃U由“元气震地”改成“捧腹大笑”。起手0.28秒，之后每0.1秒判定一次周围205范围内目标，最多21次、每次1点，全中仍为原来的21点伤害。动作总长2.6秒，体力消耗仍为28、冷却仍为5.5秒。

每次未防住的声波命中造成0.13秒僵直，会打断对手动作并短暂限制行动；没有逐次击飞/击退，避免把对手推离后无法持续判定。最后一次命中后控制自然结束，不遗留永久锁定。被控制时显示星形提示，依据实际控制计时绘制。

每次判定独立消耗：在范围外、跳过或闪避的次数不补算、不叠到后续伤害；技能被打断、角色被击倒、结束或重开后没有后台补伤害。正面全程格挡合计2点擦伤，仍保留原防御边界。单次小伤害不引发持续震屏或全局卡顿，伤害数字、粒子数量与时长受限。
