# P8.3 独立内测后端接入方案（未部署）

## 拓扑与边界

Windows 客户端只装 Electron、宠物和前端资源。发布者在构建时提供 `desktop/service-profile.json` 的固定 HTTPS DNS 来源；默认 `local` 不会自动连接外部服务，不允许命令行指定远程地址。模型凭据仅由后端秘密配置注入，不进入客户端、安装器、反馈或网页环境变量。

批准后为内测单独创建环境：独立 PostgreSQL 数据库/角色、独立 Redis、独立密钥和备份。不复用开发机 25433/26380，不向公网暴露 PostgreSQL、Redis、调试或管理端口，不拷贝开发账号、聊天或记忆。Web 入口以有效公共 CA 的 HTTPS 证书同时提供 React 静态文件和 `/api/v1`，避免跨站 Cookie 改写。宠物图形仍由本机资产网关加载，hosted 模式下本机 API 代理返回 404。

只信任反向代理来源的转发头；后端监听私有网络。前端和 CORS 使用同一个批准来源。SSE 禁止缓存/缓冲，代理及时转发增量并允许足够读超时；禁止自动重试聊天 POST、上游 SDK 或付费任务。测试证书 pin 与主机映射仅在 `desktop/test/fixtures`，不进入安装包；实际应用不能使用忽略证书错误开关。

## 上线前配置门槛

1. `environment=production`、`demo_enabled=false`，HTTPS 前端来源、Secure/Host-only Cookie、邮箱验证、Redis 认证存储和限流。生产真实模型没有额度保护会拒绝启动。
2. 实现并注入真实 `MailSender`：发送一次性验证、密码恢复/变更通知；限制频率、限制邮件服务超时、只记录固定结果。当前只有接口和 Mock，P8.3 会拒绝使用 Mock 邮件启动生产内测，尚不能完成真实用户注册投递。
3. 新数据库先应用原聊天迁移至 `0006`，再用**明确传入的新库连接**应用独立 `beta_quota_alembic.ini` 至 `q0002`。额度迁移禁止自行读取默认连接；不得对共享库运行。DDL 由迁移专用角色执行，运行角色无建表/改结构权限。
4. 邀请由组织者一次发给一个经过筛选的受邀人。后端只存邀请码 SHA-256、数量和到期时间。一个邀请只能绑定一个验证邮箱账号，一个账号只能取得一次初始额度；重复操作返回原余额。邮箱别名/多账号不能证明同一自然人，仍需人工控制邀请名单；不采集设备指纹，不宣称已防御所有女巫攻击。
5. 运营者确认允许的 DeepSeek 模型、输入 UTF-8 硬上限、输出 token 上限、价格版本及保守单请求费用上界，才可设置 `beta_pricing_attested=true`。当前测试价格全为合成数值，不可当作真实报价。未知价格时保持真实调用关闭。

## 免费额度硬限制

所有真实聊天准入与聊天记录创建在同一数据库事务中完成；锁顺序为既有 User/Chat → 数据库 UTC 日预算 → 账号 → 请求预留。跨进程共享 PostgreSQL 行锁，绝不能用工作进程内计数代替。每请求 UUID 只预留一次；账号终身/每日次数和在途并发、全局每日次数和费用预算均为硬限制。

最终序列化输入在 SDK stream 之前再次检查。派发记录先提交，才允许调用模型；重复工作租约/重启不能派发第二次。过期、跨 UTC 日、价格/模型/输出配置变化均拒绝。派发前终止可释放；派发后完成、失败、取消和未知 usage 均按一次及保守费用上界计入账本，不自动退款或重试。超出已声明 token 合约时打开当天熔断。额度耗尽仍可读取历史数据，不接支付。

账本的微美元字段是**预算占用**，不是供应商实际账单。极端崩溃留下预留时优先停止新增消费；只能由受控恢复流程核对任务终态后收敛，不能擅自清零账本或凭“没有回复”退款。真实取消能否中断上游和取消费用仍是 P8.1 未验证项。

## 运维与扩容检查

真实部署前准备：备份加密与恢复演练、最小权限、依赖安全检查、证书续期告警、请求量/429/503/未知终态/预算余额告警、数据库连接和 SSE 连接上限、固定错误码日志、日志与统计保留任务。应用日志不得包含 Cookie、密码、验证令牌、邀请码、聊天或模型凭据。反向代理访问日志同样不能记录查询串/正文/认证头，需决定 IP 保留与告知。

先批准 10 名用户且设置低的每日全局预算；观察连接失败、任务收敛、内存和用户反馈，再放到 30。50～100 人前做独立环境容量测试、备份恢复、邮件限额、SSE 并发与连接池评估。100 个合成账号的数据库准入竞态仅证明额度约束，不代表真实模型容量或真实用户体验。

本轮没有创建公开服务器、域名、邮件账号、支付或更新 feed，没有发布安装包。域名/证书、主机及费用、邮件提供商、初始邀请与预算、发行签名和公开发布均须另行确认。
