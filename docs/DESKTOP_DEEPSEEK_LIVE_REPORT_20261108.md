## 根因与最小修正

缺陷在本次新增验收驱动，而非已证明的产品聊天缺陷：

1. 驱动调用桌面 `openChat(petId)` 创建聊天窗口。
2. Electron 正在执行首次 `loadURL`；驱动看到页面对象及 URL 后，过早使用 `page.goto` 切换到新会话。
3. 新导航中断首次导航；`desktop/src/manager.cjs` 既有首次加载失败处理关闭窗口。
4. 离线复现明确记录 `page.goto: net::ERR_ABORTED; maybe frame was detached?`，最后阶段为 `navigate_new_session`。

已将驱动改为等待页面 `load` 和聊天输入框可见，再点击应用已有的新会话链接切换会话。不修改产品窗口生命周期、安全校验、聊天或取消业务逻辑。

首次失败的驱动副本保留在真实执行目录 `driver-sources/`；修正后的驱动副本保留在新的离线诊断目录。修正没有写回或覆盖原始验收结果。
